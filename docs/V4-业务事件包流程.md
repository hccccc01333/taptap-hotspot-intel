# V4 业务事件包流程（草稿交付，不自动发布）

状态：可复现流程说明，2026-11-15。对应工具：`scripts/business_event_pack.py`。

这条流程是**内容产品**的交付环节，不是 V4 浏览器 Harness 的一部分：它从公开 HTTP
原文取得证据，用系统环境里已授权的 OpenCode Go 免费模型生成情报与素材草稿，
逐条核对引文，并强制要求人工核查。它**不发布**、不写生产库、不替代 V3 的交付守卫。

## 1. 输入

一个运行前固定的事件清单（JSON 数组或 `{"events": [...]}`），每项：

```json
{
  "event_id": "miku_connect_ps_steam",
  "url": "https://example.com/article",
  "title": "事件标题",
  "source": "来源与编译关系",
  "published_at": "2026-10-22 11:21:21",
  "objective": "要确认的具体问题"
}
```

要求：公开 HTTPS 页面、无需登录、事件与 TapTap 社区相关；清单运行前固定，
失败样本保留，不按结果替换页面。

## 2. 步骤

1. **证据**：HTTP 读取原文正文（去掉评论/导航），保存 `evidence.json`；
2. **草稿自检**：`beam-free` 生成 JSON 草稿（无限额度），解析并做逐字引文核对；
3. **最终稿**：`longcat-2.5-free` 每事件**最多 1 次**生成最终稿；本地账本硬上限
   100 次，失败不重试；
4. **打包**：每个事件输出 `final.json`、`intel-material.md`、`evidence.json`；
   顶层 `summary.json`、`README.md`、`review-checklist.md`；
5. **自动检查（默认，不需要人工填表）**：引文逐字支持、事实文本中未出现在原文的
   数字/日期、素材字段完整性、unknowns 数量、Context Card 覆盖率；这些是**代理指标**，
   不是事实核验。人工核查是可选抽查，不阻塞流程；若发布，发布者仍需对内容负责。

```powershell
python -X utf8 scripts/business_event_pack.py `
  --events docs_local/business-events.json `
  --out docs_local/evaluations/business-pack-20261115
```

可选：`--no-final` 只出草稿；`--draft-model` / `--final-model` 换模型；
`--max-tokens` 调整输出预算；`--ledger` 指定调用账本。
编排模式 `--orchestrate --auto-model` 会先对 `--candidate-models` 做小 JSON 预检，
自动选择健康模型并记录 route/回退；默认跳过 Iceman（训练）与 LongCat（上限）。
`--replay-dir <包目录>` 可从已有事件包回放 evidence，不重新抓取 URL，用于离线对照
和网络波动时的复现。

## 3. 模型与计费口径

- **充分思考，不限制 reasoning**：不传任何关闭思考的参数（OpenCode Go 也不支持）；
  `max_tokens` 必须同时容纳思考与成品，默认 12000；
- 只保存 `choices[0].message.content`；`reasoning_content` / `reasoning_details`
  不落库、不进报告；
- **provider usage 含 reasoning**，按 output token 计；**成品统计只算 content 字数**，
  两者分开写，不能混成一个“token 成本”；
- LongCat 的 100 次是**调用次数**限制，思考长短不增加次数；Beam 是默认工作马，
  但 2026-11 起在部分网络/地区返回 403，可改用 `hy4-flash-free`（免费、cost=0，
  但稳定性不足，可能截断/断连）；LongCat 只用于最终稿；
- `iceman-contributor-free` 虽快且不返回可见 reasoning，但条款允许用 prompt/完成
  训练模型，不用于内部或敏感内容；
- 凭证从 `OPENCODE_API_KEY` 或本机 OpenCode `auth.json` 读取，不写入仓库/产物。

## 4. 能声明与不能声明

**可以声明**（需附事件与人工核查结果）：某事件的情报/素材草稿已生成；
引文逐字核对 N/N；模型调用次数、provider usage 与成品字数；哪些事实仍未知。

**不能声明**：草稿已发布、事实已核验、采集成功率、OCR 准确率、平台适配或增长效果。
逐字引文匹配不等于语义支持；二手编译稿需回溯原始来源与官方公告。

## 5. 限制与下一步

- 当前只做 HTTP 正文读取；游戏站点在 TUN fake-IP 环境下浏览器不可达，V4 浏览器
  未参与，故本流程不能证明 Harness 的业务价值；
- 事件类型、提示词与人工核查标准仍需在真实样本上迭代；
- 在任何“接入生产默认路径”的决定前，先完成真实事件上的人工核查与对照。
