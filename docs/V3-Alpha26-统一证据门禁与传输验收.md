# Alpha26 统一证据门禁与传输验收 / 2026-10-13

对上轮评审指出的三处代码空缺逐项补齐，并完成独立于质量实验的模型传输验收。不新增 Agent；除传输验收的 3 次授权内 Go 免费调用外未调用模型；旧实验、旧素材、已发布文档不追改。

## 一、统一证据状态门禁

证据状态词汇统一为四级，存储层写入前三者，读取层派生第四者：

| 状态 | 含义 | 写入者 |
| --- | --- | --- |
| `verified` | 事实经独立确认 | 保留值，当前无写入者（人工/独立核验路径尚未建立） |
| `needs_review` | 确定性词面核对未发现不一致；**不代表事实已获证明** | 核实器通过时写入 |
| `insufficient` | 具体事实、规则细节或整句断言未被引用支持，或与引用存在否定冲突 | 核实器命中时写入 |
| `legacy_unreviewed` | 核实器上线前保存、无核对记录 | 读取时派生（数据库保持 NULL，不追改） |

"通过词面核对"不再呈现为已验证：词面相似不等于含义相同，`needs_review` 只表示未发现词面不一致。

**门禁行为（本轮补齐的三处空缺）**：

| 入口 | 之前行为 | 现在行为 |
| --- | --- | --- |
| `game_signals()` 情报档案/公开快照 | 可能返回 insufficient 记录 | SQL 过滤；公开导出与站点快照不再含 insufficient 情报 |
| `creative_feed()`（含 held 变体） | 仅按风险门禁筛选 | 风险 + 证据双门禁；insufficient 创意保存但不展示 |
| 话题详情 `business_outputs()`（情报/素材/创意，含历史素材） | 素材仅按长度可用性过滤 | 三类成果全部排除 insufficient；素材同样排除 |
| 素材可用库 `usable_materials()`（含素材检索、创意复用） | 已排除（Alpha25） | 保持，词汇对齐 |
| 公开导出 | 素材带 verdict、信号/创意无状态 | 素材/信号/创意统一携带 `evidence_status` 字符串（含 legacy_unreviewed） |
| 透明度计数 | 无 | `overview()` 新增 `withheld_insufficient` 与 `legacy_unreviewed_materials` 计数与说明 |

保存语义不变：insufficient 记录全部**保留在数据库**（可溯源、可人工复核），不出现在可直接使用或公开展示的路径；legacy 历史记录按评审要求"先保留并标记"，不批量删除。

## 二、否定句核验（词面相似但结论相反）

新增 `negation_mismatch`：断言与引用仅差否定或结论相反时判 insufficient。双向实现：

- 断言否定、引用肯定（"不支持多人联机" vs "支持多人联机"）；
- 断言肯定、引用否定（评审示例，"支持多人联机" vs "不支持多人联机"）；
- 断言与引用同为否定时不得误报（有回归钉死）。

## 四、模型传输独立验收

**插桩**（`opencode_go.read_stream`）：每次流式调用记录首字节等待、最后数据时间、已读字节数、是否收到完整结束帧；成功写入 `stream_stats`，失败时随异常保留并写入运行步骤（`request_failure`），不记录任何正文。

**只读探测 + 3 次授权内调用（短 JSON / 小型业务 JSON / 长业务 JSON），2026-10-13 实测：**

| 形状 | 结果 | 总时长 | 首字节 | 末数据 | 读取字节 | 结束标记 | 用量（输入+输出，推理） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 短（最小 JSON） | 返回 | 6.8s | 3.4s | 6.8s | 14.1KB | 完整 | 95 + 118（推理 111） |
| 小（小型业务 JSON） | 返回 | 26.9s | 5.0s | 26.9s | 75.1KB | 完整 | 290 + 834（推理 716） |
| 长（真实规模解读包） | 返回 | **435.5s** | 5.2s | 435.5s | 1.46MB | 完整 | 9660 + 21784（推理 20759） |

- 只读探测（代理端口 / DNS / 目录端点）当次全部通过；三次调用全部用量已知，边际费用 0（不含 Go 订阅，非账户账单）。
- **长流式调用持续 435.5 秒，远超 180 秒单次读取上限，数据持续到达（末数据时间 = 总时长，无长静默）并收到完整结束帧**：此前假设的"长时间无数据的请求被 180 秒读取超时提前终止"在本轮未出现；读取超时只可能作用于超过 180 秒的静默间隙。
- 失败保留机制同时生效：中断时统计随异常写入运行步骤（本轮三调用均成功，无失败样本；该路径由离线回归钉死）。
- 观测仅对当次窗口成立；代理侧故障模式（进程 / 节点 / 隧道）仍无法区分，不排除复发。传输验收与事实准确率分开记录，原始档案在本地 `data/v3/experiments/transport-acceptance-20261013`。

## 五、边界与未确认（不宣称超过）

- 词面核对仍不等于语义核查：改写式陈述（语义等价但字面差异大）通过属预期；"verified" 无写入者，任何成果当前都不是"已证明事实"。
- 事实集 expectation 为助手标注，人工复核未完成；误放行/误拒绝率只对当前 28 例、当前核实器版本成立。
- 创意 `timing` 字段日期、普通名词张冠李戴仍为已知不拦截项。
- 传输验收只说明当次观测；代理侧故障模式（进程/节点/隧道）仍无法区分，不排除复发。基础设施失败与未知用量不进入事实准确率统计。
