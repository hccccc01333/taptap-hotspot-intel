# V4 交付层与共享前端契约

状态：MVP。**前端是共享前端，不归 V3 独占**；V3 与 V4 都只是向同一前端提供成果数据。

## 1. 契约

共享前端通过两个只读接口读取 V4 成果：

- `GET /api/v4/deliveries`：交付索引；
- `GET /api/v4/deliveries/{event_id}`：单个事件交付包。

索引 schema：`v4-delivery-index-v0.1`

```json
{
  "schema": "v4-delivery-index-v0.1",
  "deliveries": [
    {"event_id": "...", "title": "...", "status": "draft",
     "checks_passed": true,
     "delivery": "<event_id>/delivery.json",
     "preview": "<event_id>/preview.html"}
  ]
}
```

单事件交付包 schema：`v4-delivery-v0.1`，固定三类型：

- `intelligence`：情报（事实 + 引文 + unknowns）
- `material`：素材（标题/渠道/草稿/使用边界）
- `growth_creative`：增长创意（钩子、建议动作、文案草案、前置条件、状态）

数据目录由 `V4_DELIVERY_DIR` 指定，默认 `data/v4/deliveries`；V3 页面与 V4 成果可以并列展示，不存在"V3 网站"这一所有权。

## 2. 生成方式

`scripts/v4_delivery_pack.py --pack <事件包> --out <交付目录>`：

- 读取已有事件包的 evidence + final；
- 组装三类型交付包；
- 目前增长创意是**确定性结构模板**，不是 TapTap 参考库驱动；
- 生成 `index.json`、每事件 `delivery.json` 与本地交互预览 `preview.html`；
- 不发布、不写 V3 生产库。

## 2.1 公开静态部署路径

远端 Pages 没有后端，使用静态交付数据：

- 导出脚本：`python -X utf8 scripts/export_v4_deliveries_public.py`
- 输出：`spatial/public/v4-deliveries/`（`index.json` + 每事件 `delivery.json`/`preview.html`）
- Vite 构建时复制到 `dist/v4-deliveries/`，共享前端在 `VITE_PUBLIC_RESULTS_URL` 模式下
  读取 `${BASE_URL}v4-deliveries/index.json`；
- 导出会剥离模型 usage 等内部计费字段，只保留公开事实、引文、来源 URL 和创意草案；
- 该目录需要随交付更新重新导出并提交；不是实时同步。
- 当前已导出 5 个近期 TapTap 事件；模型创意质量门槛为字段完整、未支持数字 0、
  不复制参考样本长文；不合格时回退确定性草案。

## 3. 当前边界

- 增长创意已接入最小 TapTap 公开参考库（结构/节奏，不复制原文），但仍为确定性生成；
- 共享前端已新增「V4 交付」页签，读取 `/api/v4/deliveries`；公开静态成果模式下没有该 API；
- 交付仍是草稿，未做独立事实核验；
- 三类型质量检查是代理指标，不等于业务可用性。
